# 🌩️ 霓虹风暴 NeonStorm

单文件、零依赖的网页几何霓虹射击游戏。Canvas 2D 渲染 + WebAudio 合成音效,双击即玩,无需安装任何东西。

## 玩法

- **WASD / 方向键** 移动 · **鼠标** 瞄准 · 默认自动开火(按住左键也可手动射击)
- **F** 切换自动开火 · **M** 静音 · **P** 暂停 · 触屏支持(按住拖动 = 虚拟摇杆)

## 特色

- ✈️ **拟真 2D 战机**:金属渐变机身、座舱玻璃、双垂尾、双发尾焰、翼下挂弹
- 📈 **成长系统**:击杀获取经验,升级三选一(火力 / 多管齐射 / 射速 / 穿甲 / 引擎 / 装甲 / 护盾 / 僚机 / 暴击)
- ⚡ **终极技能「超载爆发」**:击杀充能,满格释放——慢镜头 + 全屏清场 + 5 秒无敌火力全开 + 得分 ×2
- 👾 **异星结晶体敌群**:追踪猎手、分裂母体、带蓄能预警的炮台,波次推进难度缓升
- 🔥 连击倍率(最高 ×8)、粒子爆炸、屏幕震动、冲击波、合成音效

## 运行

方式一:直接双击 `index.html`
方式二:本地起服务(推荐):

```bash
python -m http.server 8321
# 打开 http://localhost:8321
```

## 技术

纯原生 HTML + CSS + JavaScript 单文件,无任何框架与外部资源,离线可玩。最高分保存在浏览器 localStorage。
